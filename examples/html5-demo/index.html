FastPix Data SDK + Shaka Player

Plain HTML5 examples, no bundler. Each page loads Shaka Player from a CDN and the FastPix Shaka SDK from the local repo build (../../dist/index.js).

  • hls.html — HLS (.m3u8) stream tracked with FastPix
  • dash.html — DASH (.mpd) stream tracked with FastPix

Serve from the repo root so ../../dist/index.js resolves:

npm run build   # produces dist/index.js
npx serve .     # then open /examples/html5-demo/

Set your Workspace Key (workspace_id) in each page — get one from dashboard.fastpix.com.
